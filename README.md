## Customization

### Update Company Details
Edit the contact information in `index.html`:
- Phone number
- Email address
- Company address

### Modify Colors
Edit the color variables in `styles.css`:
- Primary colors: `#1e3c72`, `#2a5298`
- Accent color: `#ffc107`
- Secondary colors: `#667eea`, `#764ba2`

### Add Services
Add new service cards in the Services section of `index.html`

### Contact Form
The contact form currently uses email links. To add backend processing, connect it to:
- EmailJS
- Formspree
- Backend service
